# DP-700 · Fabric Data Engineer

Labs for [Exam DP-700: Implementing Data Engineering Solutions Using Microsoft Fabric](https://learn.microsoft.com/credentials/certifications/resources/study-guides/dp-700). Target exam date: May 2027.

Planned topics: PySpark, Delta Lake (partitioning, time travel, MERGE), full and incremental loads with SCD, advanced pipelines, real-time with Eventstreams and Eventhouse, monitoring, and Lakehouse and Warehouse optimization.

Labs will be added from February 2027.
